# Telugu Crop Disease Diagnosis and Pesticide Recommendation System using NLP and TensorFlow

## Abstract
This project is a Natural Language Processing based crop disease diagnosis system where farmers can enter crop symptoms in Telugu. The system translates Telugu text into English and uses a TensorFlow NLP model to predict crop diseases. Based on the predicted disease, the system recommends pesticides, low-cost alternatives, and displays pesticide prices based on farmer location. The system is implemented using Python, TensorFlow, and Streamlit.

## Technologies Used
- Python
- TensorFlow
- Natural Language Processing (NLP)
- Streamlit
- Pandas
- Scikit-learn
- Google Translate API

## System Workflow
1. Farmer enters symptoms in Telugu
2. System translates Telugu to English
3. NLP model predicts disease
4. System recommends pesticide
5. Shows low-cost alternative
6. Farmer enters location
7. System shows pesticide price and nearby shop

## Future Implementation / Future Scope
In future, this system can be extended into a farmer–seller platform. Pesticide sellers and agricultural shops can register on the website and update pesticide prices, stock availability, and shop location. Farmers can compare prices from multiple sellers, check availability, and contact sellers directly for purchasing pesticides. The system can also be integrated with GPS location services and agricultural market APIs to provide real-time price updates and nearby shop recommendations.
